# 🎨 Textual TUI-Creator — Visual GUI & TUI Builder for Python Textual

**Textual TUI-Creator** is an intuitive, drag-and-drop visual interface designer and native code generator built on top of [Textual](https://github.com/Textualize/textual). Build production-ready Python terminal apps without typing repetitive boilerplate.

---

### 🌟 Features
- **🌐 Full Bilingual Support (DE / EN):** Instant language switching via the <kbd>L</kbd> key or via `--lang de` / `--lang en`.
- **📐 3-Column Layout:** Tree view hierarchy, real-time visual canvas, and property inspector.
- **⚡ 1-Click Code Generation:** Produces clean, idiomatic Python Textual code with event handlers and Catppuccin-themed TCSS styling.
- **📁 Built-in Templates:** Start from scratch (Blank Canvas) or pick pre-built Dashboard and Form templates.
- **🔄 Undo / Redo & History:** Full state stack with Ctrl+Z and Ctrl+Y shortcuts.

---

### 🚀 Quick Start

```bash
git clone https://github.com/Graba92/textual-tui-creator.git
cd textual-tui-creator
./setup.sh
./run.sh

# Run with forced language
python3 tui_creator.py --lang en
python3 tui_creator.py --lang de
```
