# 🎨 Textual TUI-Creator — Visueller Interface-Builder für Textual

Du möchtest moderne Konsolen- und Terminal-Oberflächen (TUI) in Python erstellen, ohne stundenlang Widgets von Hand anzuordnen?

**Textual TUI-Creator** bietet dir:
- **Zweisprachig (Deutsch / Englisch):** Wechsle mit Taste `L` oder `--lang en`/`--lang de` blitzschnell die Sprache.
- **Visueller Editor:** Baue deine Oberfläche mit Containern, Buttons, Inputs und Datatables im visuellen Baum zusammen.
- **Automatischer Code-Export:** Generiert auf Tastendruck lauffähigen Python-Code inklusive Catppuccin-Styling.

### Installation & Start
```bash
git clone https://github.com/Graba92/textual-tui-creator.git
cd textual-tui-creator
./setup.sh
python3 tui_creator.py
```
